## 📁 Projects

The course includes several hands-on projects, each focused on a different AI topic:

### 🧠 Project 0: Search
- **degrees**: Finding the shortest path between actors using graph search algorithms.
- **tictactoe**: Implementing a perfect AI player for Tic-Tac-Toe using Minimax.

### ♞ Project 1: Knowledge
- **knights**: Solving logic puzzles using propositional logic and model checking.
- **minesweeper**: Creating an AI that plays Minesweeper logically.

### 👨‍👩‍👧 Project 2: Uncertainty
- **heredity**: Applying probability and Bayes' Rule to model genetic inheritance.
- **pagerank**: Building a PageRank algorithm to rank pages by importance.

### 🔤 Project 3: Optimization
- **crossword**: Using constraint satisfaction to generate a valid crossword puzzle.

### 🎲 Project 4: Learning
- **nim**: Reinforcement learning agent that learns to play the game of Nim.
- **shopping**: Training a Naive Bayes classifier to predict online shopping behavior.

### 🧾 Project 5: Language
- **traffic**: Using a neural network to predict traffic patterns.

### ❓ Project 6: Questions
- **parser**: Building a parser to understand the grammar of sentences.
- **questions**: Using NLP to answer questions from a text document.
